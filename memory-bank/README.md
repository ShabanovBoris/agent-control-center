# Memory Bank

Контекст для продолжения работы над Agent Control Center. Для новой задачи начни с [текущего контекста](activeContext.md) и [состояния проекта](progress.md), затем открой нужный раздел.

| Файл | Содержимое |
| --- | --- |
| [projectbrief.md](projectbrief.md) | Цель и границы проекта |
| [productContext.md](productContext.md) | Сценарии панели и ожидаемое поведение |
| [systemPatterns.md](systemPatterns.md) | Архитектура, владение состоянием и контракты |
| [techContext.md](techContext.md) | Стек, конфигурация, запуск и диагностика |
| [activeContext.md](activeContext.md) | Последние изменения и сведения для продолжения |
| [progress.md](progress.md) | Что работает, проверки и известные ограничения |

Команды запуска и настройка описаны в [README проекта](../README.md). При расхождении документации с реализацией сверяйся с кодом. Записывай результаты проверок с датой и указывай, что именно проверено. Обновляй Memory Bank по запросу пользователя. Значения ключей и токенов храни только в локальной конфигурации.
