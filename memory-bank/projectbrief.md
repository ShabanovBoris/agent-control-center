# Проект

Agent Control Center — локальная веб-панель для управления сессиями coding agents на нескольких Agent Host. Она даёт один интерфейс для Claude, Codex и Gemini, сохраняя каждый разговор в его хосте. Один и тот же разговор может быть доступен из панели и другого AHP-клиента.

- Основной хост обслуживает Claude через cheapvibecode и Codex с авторизацией ChatGPT. Второй хост запускает Gemini через cheapvibecode в среде Codex.
- Агентную работу выполняют отдельные процессы VS Code Agent Host и их SDK. Окно редактора для запуска панели не требуется.
- Панель отвечает за управление сессиями и представление состояния. Хост отвечает за сессии, выполнение инструментов, политику разрешений и доступные возможности агента.

Подключения и команды описаны в [техническом контексте](techContext.md), пользовательские сценарии — в [контексте продукта](productContext.md).
