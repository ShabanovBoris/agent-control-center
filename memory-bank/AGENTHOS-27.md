# AGENTHOS-27: несколько терминалов в общем списке

Статус: backlog. Создана после приёмки AGENTHOS-26.

## Запрос владельца

Несколько сессий терминалов одновременно, чтобы запускать разные TUI-агенты (например `kent`
и ещё один). Отображаться должны «в общем списке с сессиями чатов, только с чёрной обводкой».

## Граница, выбранная владельцем

Список открытых терминалов живёт **внутри** страницы `#terminal`. Общий сайдбар с сессиями
чатов не трогаем, `#terminal` остаётся отдельной страницей — решение AGENTHOS-26 не отменяется.
«Общий список» = список всех открытых терминалов на странице терминала; чёрная обводка —
визуальное отличие выбранного. Не расширять до переделки сайдбара.

## Что уже есть в коде (не изобретать заново)

- Хосты отдают список терминалов в root: `TerminalInfo { resource, title, claim, lifecycle }`.
  Это источник истины; отдельная карта в панели не нужна (`hostTerminals` в `server/hub.ts`).
- `server/hub.ts`: лимит 8 своих PTY, атомарное вытеснение `reserveTerminalSlot`
  (`terminalDisposals`, `pendingTerminals`, `terminalClosings`), автоочистка
  `sweepTerminals` с `ACC_TERMINAL_IDLE_MS` (30 мин), терминалы агентов не трогаются.
- `src/terminal-session.ts`: URI в localStorage по паре хост+папка + последняя пара.
  Для нескольких PTY эту схему придётся пересмотреть — сейчас она даёт один терминал на папку.
- `src/ui/TerminalEmulator.tsx`: xterm в ленивом чанке, ввод через `term.onData`,
  `screenReaderMode: false` (см. AGENTHOS-26 — с `true` не доезжает кириллица/IME).

## Открытые вопросы для планирования

- Заголовок строки: `TerminalInfo.title` от хоста, cwd или имя папки?
- Показывать ли только свои PTY или все из root (у чужих `claim.kind === 'client'` с чужим clientId).
- Как хранить набор открытых терминалов в localStorage вместо текущей пары хост+папка.
- Что происходит с лимитом 8: страница теперь может держать несколько PTY одновременно,
  вытеснение старейшего может выкинуть тот, что сейчас смотрят.

## Проверено на живом стенде (для контекста)

Терминал работает на всех трёх локальных хостах (`local`, `wbllm`, `glm`): `createTerminal`
возвращает `running`, кириллица доходит, `seq 1 200000` не вешает вкладку, 390×844 без
горизонтального скролла, F5 и уход-возврат подхватывают тот же shell.
