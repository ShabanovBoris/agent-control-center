# Состояние проекта

Реализованы создание и открытие сессий, поток сообщений и инструментов, подтверждения, ответы на вопросы агента, отмена хода, переподключение, выбор модели и reasoning, расход токенов, архивирование и восстановление. Обрабатываются сессии, удалённые из другого клиента. Форма создания поддерживает диалог macOS и восемь последних папок на хост.

- **18 ноября 2026** — `npm run typecheck` прошёл. Все 51 тест прошли через `node --import tsx --test server/*.test.ts src/*.test.ts`. Обычный `npm test` в этой среде остановился на `EPERM` при открытии IPC-сокета CLI `tsx`.
- **До переноса рабочей копии** — по переданному отчёту прошли 51 тест, проверка TypeScript и production-сборка. В интерфейсе проверили выбор и отмену папки, создание сессии, историю после перезагрузки и разделение истории по хостам. Эти ручные проверки при инициализации не повторялись.

Известные ограничения панели: POSIX-пути, одна рабочая папка при создании, ограниченный просмотр инструментов без отдельных представлений терминалов и изменений файлов, отсутствие управления режимом подтверждений. В уже начатой сессии Claude хост может продолжать использовать прежнюю модель. Список ограничений и обходные пути описаны в [README проекта](../README.md).
