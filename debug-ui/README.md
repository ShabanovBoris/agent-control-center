# Резервная панель агентов

Панель открывается на [127.0.0.1:5174](http://127.0.0.1:5174). Сервер обслуживает HTML, CSS и JavaScript из этой папки и напрямую подключается к AHP-хостам под отдельным идентификатором клиента. Достаточно Node.js 22+ и собственной установки SDK в `debug-ui/node_modules`.

Установите зависимости и запустите сервер из корня проекта.

```sh
npm ci --prefix debug-ui
npm start --prefix debug-ui
```

На странице можно открыть сессию, выбрать чат, просмотреть последние 20 ходов, отправить сообщение, ответить на запрос или отменить его, разрешить или отклонить действие инструмента и остановить ход. Форма «Новая сессия» позволяет выбрать хост, агента и абсолютную рабочую папку.

При сбое AHP-хоста страница остаётся доступной. На открытой вкладке панель запрашивает состояние чата каждые 3,5 секунды. Отправки и подтверждения требуют ответа хоста. При отказе или истечении таймаута текст остаётся в поле.

Обе панели читают общий `hosts.json` в корне проекта, поэтому используют одни и те же хосты,
названия и токены: «Claude · cheapvibecode + Codex · ChatGPT» и «CheapVibeCode · Codex».
Основная панель подключается через backend, резервная — напрямую под отдельным идентификатором клиента.
`ACC_DEBUG_CONFIG` может указать другой JSON-файл для диагностики. Порт резервной панели —
`debugPort` (по умолчанию `5174`). Пути `tokenFile` считаются относительно файла конфигурации
и читаются сервером при подключении. Список доступных агентов предоставляет сам AHP-хост;
`providers` можно задать явно только для конкретного хоста при необходимости диагностики.
После изменения конфигурации перезапустите резервную панель.

Для прямой ссылки передайте `host` и `session` в адресе страницы, например `/?host=local&session=ahp-session%3A%2F...`. Список показывает до 100 сессий на хост.

```sh
npm test --prefix debug-ui
```
